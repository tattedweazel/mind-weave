# Security policy

## Reporting a vulnerability

**Do not** open a public GitHub issue for undisclosed security vulnerabilities.

Please report them using **[GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)** for this repository: open the repository **Security** tab and use **Report a vulnerability**. Repository owners should enable **Settings → General → Security → Private vulnerability reporting** if it is not already on.

## Maintainer context

High-level security posture and periodic review notes for the application are maintained in [docs/Audits/SECURITY_AUDIT.md](docs/Audits/SECURITY_AUDIT.md). That document is **not** a substitute for private disclosure of new issues.
